# Промпт для поднятия резюме — ежедневное обновление

**Использование:** `hh-applicant-tool boost-resume` (автоматически, без промпта)

---

## Автоматизация поднятия резюме

HH.ru позволяет поднимать резюме в поиске **1 раз в 24 часа**.

### Команда
```bash
hh-applicant-tool boost-resume
```

### Когда запускать
- **Утром**, в начале рабочего дня (9:00-10:00)
- **Перед откликами** — чтобы резюме было в топе
- **Не чаще 1 раза в сутки** на одно резюме

### Скрипт для cron (ежедневно в 9:00)
```bash
# ~/.config/crontabs/root
0 9 * * * cd /path/to/project && hh-applicant-tool boost-resume >> /var/log/hh-boost.log 2>&1
```

### Проверка статуса
```bash
# Проверить, можно ли поднять резюме
hh-applicant-tool list-resumes

# Если статус "published" и прошло 24ч — можно поднимать
```

---

## Обновление контента резюме (раз в 1-2 недели)

Если резюме не откликается — обнови описание:

```bash
# Через API
hh-applicant-tool call-api -X PUT /resumes/{ID} \
  -d '{"title": "Frontend-разработчик (React, TypeScript)", ...}'
```

### Что обновлять
1. **Заголовок** — добавить ключевые технологии
2. **Навыки** — актуализировать под рынок
3. **Опыт** — добавить последние проекты
4. **Зарплатные ожидания** — по текущему рынку
