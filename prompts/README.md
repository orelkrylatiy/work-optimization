# 🤖 Промпты для автономной работы HH.ru

## Структура

```
prompts/

├── cover-letter.prompt          # Генерация сопроводительных писем

└── templates/
    ├── cover-letter-base.txt    # Базовый шаблон письма
```

## 🔄 Оптимальный Workflow (5-7 итераций)

### Цикл работы (повторять 5-7 раз)

```
┌─────────────────────────────────────────────────────────┐
│  ИТЕРАЦИЯ N (из 5-7)                                    │
├─────────────────────────────────────────────────────────┤
│  1. BOOST RESUME (1 раз в 24 часа)                      │
│     └─→ Если прошло <24ч → ПРОПУСТИТЬ                   │
│                                                         │
│  2. APPLY VACANCIES (80-120 откликов)                   │
│     └─→ Если лимит → ПРОПУСТИТЬ                         │
│     └─→ Генерация УНИКАЛЬНЫХ писем под вакансию         │
│                                                         │
│  3. CHAT RESPONSES (ответы работодателям)               │
│     └─→ Проверка новых сообщений                        │
│     └─→ Если нет новых → ПРОПУСТИТЬ                     │
│     └─→ Генерация УНИКАЛЬНЫХ ответов (контекст чата)    │
│                                                         │
│  4. FOLLOW-UP (тишина >2 дней)                          │
│     └─→ Если все ответили → ПРОПУСТИТЬ                  │
│     └─→ Вежливое напоминание                            │
│                                                         │
│  5. TIMEOUT / PAUSE (30-60 мин)                         │
│     └─→ Избежание блокировки HH.ru                      │
└─────────────────────────────────────────────────────────┘
                          ↓
                  ИТЕРАЦИЯ N+1
```

## 📊 Decision Matrix

| Ситуация | Действие | Промпт |
|----------|----------|--------|
| Резюме не в топ >24ч | Boost resume | `boost-resume.prompt` |
| Откликов <100 за день | Apply vacancies | `apply-vacancies.prompt` |
| Новые сообщения в чатах | Ответить персонально | `chat-response.prompt` |
| Тишина >2 дней | Follow-up | `follow-up.prompt` |
| Лимит откликов | Пауза до завтра | - |
| Ошибка API | Retry + лог | - |

## 🎯 Ключевые принципы

1. **Уникальность:** Каждое сообщение генерируется заново с вариациями
2. **Контекст:** Ответы в чатах учитывают историю переписки
3. **Безопасность:** Таймауты между итерациями (30-60 мин)
4. **Адаптивность:** Пропуск шагов если не нужно
5. **Лимиты:** Не превышать 100-150 откликов/сутки
